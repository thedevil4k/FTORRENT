# Historical documents

These files describe how parts of FTorrent were built at a point in time. They
are kept for the decisions they record, not as a description of the current
code, and any statement in them may be out of date.

| file | what it is |
| :--- | :--- |
| `PROGRESS.md` | the "project complete" report from the first milestone |
| `MULTITHREADING-SUMMARY.md` | the multi-threading completion report |
| `RESOURCES.md` | the visual-resources phase report |
| `DIALOGS.md` | the phase that built the dialogs |
| `UI-DESIGN.md` | the first interface design |
| `TECHNICAL-REFERENCE.md` | an early class-by-class overview |
| `install-dependencies.md` | the old Windows dependency notes, superseded by `COMPILE-GUIDE.md` |

For what the code does today read, in this order: `README.md` (product),
`ARCHITECTURE.md` (how it is put together), `AGENTS.md` (the rules a change has
to follow) and `USER-GUIDE.md` (using the client).
